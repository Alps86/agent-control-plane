## Offene fachliche Entscheidungen

- Welche konkreten Datenquellen und Tools der erste Eino-Agent außer internen Aufgaben lesen oder ausführen darf, muss für eine reale Ausführung festgelegt werden. Direkte Shell, HTTP und Dateisystemzugriffe bleiben grundsätzlich ausgeschlossen.
- Für Codex CLI muss pro Profil die Sperre direkter Tool- und Nebenwege nachgewiesen werden; andernfalls bleibt der Adapter gesperrt. Nur die Go-Anwendung darf begrenzte Artefakte schreiben.
- Ob in V1 weitere Paperclip-Adapter, externe Connectors, Skill-Importe, isolierte Workspaces oder das Alpha-Plugin-System benötigt werden, ergibt sich aus der Vollumfangsabnahme. Bis dahin sind diese Bereiche sichtbar im Backlog, nicht still gestrichen.
- Rollen Reviewer, Reporter und Monitoring beschreiben Zuständigkeiten von Agenten beziehungsweise Arbeitsabläufe. Wegen des ausgeschlossenen Logins sind sie keine menschlichen Anmelderollen.
